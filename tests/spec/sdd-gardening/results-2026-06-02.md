## Findings

   stays quiet, invocation (E) delegates.
2. **Marginal value clarified by RED** — the baseline agent already knows to
   extract ADRs (Superpowers/MADR instinct), so the skill's real value is
   **consistency (the triad) + archiving the raw**, not teaching extraction.
3. **CONFLICT — `docs/records/` vs `docs/decisions/`. → RESOLVED.** The baseline
   reached for `docs/decisions/` (MADR norm, and metapowers' own AGENTS.md
   convention); our triad had used `docs/records/`. Aligned the triad to
   `docs/decisions/` across the rule, skill, subagent, and technote — the triad is
   now `spec` / `decisions` / `design`, matching agent instinct and tooling.
4. **Superpowers integration** — with wip present, `sdd-gardening` was chosen over
   `finishing-a-development-branch`; both are relevant at wrap-up and the rule
   sequences them. Needs the end-to-end dev-role harness to confirm the rule makes
   finishing → gardening actually fire in a live session.
