## Verdict — is the bundle load-bearing?

**Partially, on this fixture — with one clear win and two no-deltas.**

- The **single** measurable behavioral delta is **mode purity**: GREEN obeys
  _one document, one Diátaxis mode_ by splitting the integration guide into its
  own linked file, where RED welds it into `usage.md`. This is exactly the
  `tech-writing` umbrella's cardinal rule (§2) and the integration-guide routing
  (§1 → how-to + reference link-out), and it fired with no prompting. That delta
  is real and load-bearing.
- **Activation is clean** (skill invoked once in GREEN, zero in RED).
- BUT the **house-style** and **drift** probes show **no RED→GREEN delta**: the
  base Opus model already wrote clean second-person, present-tense, sentence-case
  prose, dropped "click here", and corrected the stale signature **without** the
  `tech-writing-style` rule installed. On this fixture the rule is **not**
  load-bearing for those probes — the model does the right thing unaided.

### REFACTOR signals (be honest)

1. **The fixture under-stresses the house-style rule.** The drift is small and
   obvious enough that the base model fixes it and writes house-conformant prose
   on its own, so RED ≈ GREEN on House style and Drift. To prove the rule is
   load-bearing, the RED baseline must actually fail first. Suggest hardening the
   fixture: a longer drifted doc that the base model is more likely to copy
   verbatim (preserving "we"/"click here"/future tense and the stale signature),
   or a doc whose stale signature is plausible enough that an unaided model keeps
   it. Right now these two probes are **inconclusive**, not GREEN.
2. **The "Media" probe in `dev-role-harness.md` is unreachable with this
   fixture** — there is no auth/token relationship in `calc.py`/`usage.md` to
   route to `tech-diagramming`. Either add a diagram-shaped relationship to the
   fixture or drop the Media row from the pass/fail table for this sandbox.
3. **Harness portability:** the literal `timeout 420 claude …` does not run on
   macOS (no `timeout` binary). Use `gtimeout` (coreutils) or remove the prefix
   and rely on the caller's bound.

Bottom line: the **`tech-writing` umbrella skill is load-bearing for mode purity
and activates correctly**; the **`tech-writing-style` rule is not provably
load-bearing on this fixture** because the RED baseline never failed the style
or drift probes. The eval should be treated as **GREEN on mode-purity +
activation, inconclusive on house-style + drift**, pending a harder fixture.
