**Plan**

   Class: standard (default: user-facing screens that display personal data. AGENTS.md has no class for `src/ui/`)

   Class: standard (same screen and same code as task 1)
3. Add tests in a new `tests/test_settings_view.py`. Cover three cases: the email appears, a user with no email still renders, and an email containing HTML characters comes out escaped.
   Class: standard (tests of standard code)
