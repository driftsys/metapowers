## Before dispatch: three things you need to decide

1. **What "rejected with an authentication error" means (REQ-AUTH-015).** Today `validate_session` returns `None` for an unknown token, and `test_unknown_session` relies on that. **My recommendation:** add an `AuthenticationError` exception and raise it for expired sessions. Unknown tokens keep returning `None`, since the spec doesn't cover them. The other option is to raise for both, which changes current behaviour and breaks that existing test.
2. **The timing rules (REQ-AUTH-014).** "30 minutes after its last request" means the timer resets on each request, so `validate_session` has to update a `last_seen` time when it succeeds. **My recommendation:** a session is expired once `now - last_seen >= 1800` seconds, and expired sessions are removed from `SESSIONS`.
3. **The class doesn't match the repo.** `AGENTS.md` lists only `src/payments/` as critical, not `src/auth/`. I'm going with your "critical" label. You may want to add `src/auth/` to `AGENTS.md` separately.
