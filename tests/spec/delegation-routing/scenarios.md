# delegation-routing - scenario battery

Battery for the `delegation-routing` skill (`skills/delegation-routing/SKILL.md`).
Criteria are written before any run and checked by reading each reply.

## Harness

- Fixture: `fixture/`, copied from `../delegation-classes/fixture`, plus
  `docs/spec-session-expiry.md` (REQ-AUTH-014, REQ-AUTH-015), `ci.log` and
  `data/tickets/` (40 small support-ticket files, generated by script).
- RED: no skill content. `claude -p --safe-mode` skips user rules, skills and
  settings. Run `run-red.sh` through `bash -lc`.
- Cells: Claude Code with Opus 5.5 and Claude Code with Sonnet 5.5, 3 runs per
  scenario and cell.
- **Copilot is out of this battery**: its plan usage limit is reached. Its
  table in the skill is untested.
- Each prompt states the task class and asks the model to list the subagents it
  would dispatch (role, model, effort, brief contents) without dispatching.
- The pass criteria use the Claude Code table of the skill.
